# Canvases

A canvas is a board for thinking in space: text, your notes, images, and files laid out on an endless surface and joined by arrows. Use one to plan a project, brainstorm, collect research, or sketch how things connect.

A canvas is a `.canvas` file in your notes folder, in the open [JSON Canvas](https://jsoncanvas.org) format, so other apps that read the format can open it too.

## Making a canvas

Choose **File → New Canvas**, or right-click a folder and choose **New Canvas**, then type a name for it in the note list.

## Adding cards

| To add | Do this |
|---|---|
| A text card | **Double-click** an empty spot |
| A note | Drag notes from the note list onto the canvas |
| An image or other file | Drag files from Finder, or paste an image |
| A photo, scan, or sketch from your iPhone or iPad | Right-click an empty spot and choose **Take Photo**, **Scan Documents**, or **Add Sketch** |
| A web link | Paste a web address |

Text cards are written in Markdown, just like a note: headings, lists, tasks, links, math, and diagrams all work.

Note cards show the note itself, and you can edit it right there: double-click the card and type. Your changes are saved to the note.

## Arranging

Drag cards to move them, and drag the edges to resize them. Select several cards and choose **Group** to keep them together, or use the color button to color cards, groups, and arrows.

## Arrows

Hover over a card to see a dot on each side, and drag from a dot to another card to join them. Let go on empty space to make a new card there, already joined. Double-click an arrow to give it a label.

## Moving around

| To | Do this |
|---|---|
| Pan | Scroll with two fingers, or hold Space and drag |
| Zoom | Pinch, or hold ⌘ and scroll |
| See everything | **⇧1** |
| Zoom to the selection | **⇧2** |
| Actual size | **⇧0** |

## Keys on a canvas

| Key | Does |
|---|---|
| ⌫ | Delete the selection |
| ⌘C, ⌘X, ⌘V | Copy, cut, and paste cards, with the arrows between them |
| ⌘D | Duplicate the selection |
| ⌥-drag | Move copies of the cards |
| Return | Edit the selected card, or open the selected file |
| Escape | Stop editing, or clear the selection |
| Tab, ⇧Tab | Select the next or previous card |

Right-click a card for more, like **Convert to Note**, which turns a text card into a separate note.

## Canvases and the rest of Jetfold

Canvases are part of your notes: search finds them by the text on their cards, a note on a canvas shows the canvas in backlinks, and renaming a note keeps the canvases that show it up to date. **File → Export** saves a canvas as a PDF, a PNG image, a web page, or Markdown (see [Exporting](exporting.md#canvases)).
