# Canvases

A canvas is an endless board for thinking visually. Lay out text, notes, images, and files, and draw arrows to show how they relate. Use a canvas to plan a project, brainstorm, or collect research.

Canvases are saved as `.canvas` files in your notes folder, in the open [JSON Canvas](https://jsoncanvas.org) format, so other apps that support the format can open them.

## Making a canvas

Choose **File → New Canvas**, or right-click a folder and choose **New Canvas**, then type a name for the canvas in the note list.

## Adding cards

| To add | Do this |
|---|---|
| A text card | **Double-click** an empty spot |
| A note | Drag notes from the note list onto the canvas |
| An image or other file | Drag files from Finder, or paste an image |
| A photo, scan, or sketch from your iPhone or iPad | Right-click an empty spot and choose **Take Photo**, **Scan Documents**, or **Add Sketch** |
| A web link | Paste a web address |

You write text cards in Markdown, as in a note, with headings, lists, tasks, links, math, and diagrams.

A note card shows the note. Double-click the card to edit the note on the canvas, and your changes are saved to the note.

## Arranging

Drag cards to move them, and drag the edge of a card to resize it. To keep several cards together, select them and choose **Group**. Use the color button to color cards, groups, and arrows.

## Arrows

Hover over a card to see a dot on each side. Drag from a dot to another card to connect them with an arrow. Release on empty space to create a new, connected card there. To label an arrow, double-click it.

## Moving around

| To | Do this |
|---|---|
| Pan | Scroll with two fingers, or hold Space and drag |
| Zoom | Pinch, or hold ⌘ and scroll |
| See everything | **⇧1** |
| Zoom to the selection | **⇧2** |
| Actual size | **⇧0** |

## Keys on a canvas

| Key | Does |
|---|---|
| ⌫ | Delete the selection |
| ⌘C, ⌘X, ⌘V | Copy, cut, and paste cards, with the arrows between them |
| ⌘D | Duplicate the selection |
| ⌥-drag | Move copies of the cards |
| Return | Edit the selected card, or open the selected file |
| Escape | Stop editing, or clear the selection |
| Tab, ⇧Tab | Select the next or previous card |

Right-click a card for more options, such as **Convert to Note**, which turns a text card into a separate note.

## Canvases and the rest of Jetfold

You can search for a canvas by the text on its cards. If a note is on a canvas, the canvas is listed in the backlinks for the note, and renaming the note updates the canvas. Use **File → Export** to save a canvas as a PDF, a PNG image, a web page, or Markdown (see [Exporting](exporting.md#canvases)).
