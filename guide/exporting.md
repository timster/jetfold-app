# Exporting

Export a note to share it with people who don't use Jetfold, or to open it in another app. Choose **File → Export**, or press **⇧⌘E** to export a PDF.

| Format | What you get |
|---|---|
| **HTML** | A stand-alone web page with the images embedded |
| **PDF** | A paginated document |
| **EPUB** | An e-book with the images included, for any e-book reader |
| **TextBundle** | The Markdown and images in one package that other Markdown apps can open |
| **Plain Text** | The text without Markdown symbols |

## HTML, PDF, and EPUB

These exports keep the formatting, code colors, math, and images, in a clean light style.

![Atlas Launch Plan exported as a PDF: headings, a quote, a table, and a task list](screenshots/39-pdf-export.png)

## TextBundle

A TextBundle is a single file with the Markdown of a note and copies of its images. Many Markdown apps open TextBundles directly, so this is the easiest way to move a note with pictures to another app.

## Canvases

**File → Export** has these formats for canvases:

| Format | What you get |
|---|---|
| **PDF** | The whole board on one page |
| **PNG Image** | The board as a picture, for chats and slides |
| **HTML** | A stand-alone web page of the board |
| **Markdown** | The cards as a document, with the arrows listed as connections |
