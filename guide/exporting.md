# Exporting

Export any note to share with people who don't use Jetfold, or to take to another app. Choose **File → Export**, or press **⇧⌘E** for a PDF.

| Format | What you get |
|---|---|
| **HTML** | A stand-alone web page, images embedded |
| **PDF** | A paginated document |
| **EPUB** | An e-book for any book reader, images inside |
| **TextBundle** | The Markdown and images, in one package other Markdown apps open |
| **Plain Text** | The words, without the Markdown symbols |

## HTML, PDF, and EPUB

These look like the note does in Jetfold, in a clean light style, with formatting, code colors, math, and images.

![Atlas Launch Plan exported as a PDF and open in a PDF viewer: headings, a quote, a table, and a task list](screenshots/39-pdf-export.png)

## TextBundle

A TextBundle is a single file holding the note's Markdown and a copy of every image the note shows. Many Markdown apps open TextBundles directly, which makes it the easiest way to move a note with pictures to another app.
