# Keyboard Shortcuts

Every command is also in the command palette (⌘P), including the ones without a shortcut.

## Notes and windows

| Action | Shortcut |
|---|---|
| New note | ⌘N |
| New note from template | ⌥⌘N |
| New folder | ⇧⌘N |
| Open today's note | ⌘T |
| Show note history | ⇧⌘H |
| Note Info | ⌥⌘O |
| Commit changes | ⇧⌘K |
| Export as PDF | ⇧⌘E |
| Save now (Jetfold also saves automatically) | ⌘S |
| Move selected notes to Trash (in the note list) | ⌘⌫ |
| Move the selected folder to Trash, or remove the selected tag (in the sidebar) | ⌘⌫ |
| Rename the selected folder (in the sidebar) | Return |
| Close window | ⌘W |
| Show the main window | ⌘0 |
| Settings | ⌘, |
| Jetfold Guide (Help menu) | ⌘? |
| Quit | ⌘Q |

## Finding

| Action | Shortcut |
|---|---|
| Command palette | ⌘P |
| Go to note | ⌘O |
| Search in notes | ⇧⌘F |
| Go to heading | ⇧⌘O |
| Go to Tasks | ⌥⌘L |
| Go to Agenda | ⌥⌘A |
| Back / Forward (notes you've visited) | ⌘[ / ⌘] |
| Find in note | ⌘F |
| Find and replace | ⌥⌘F |
| Find next / previous | ⌘G / ⇧⌘G |
| Use selection for find | ⌘E |

## View

| Action | Shortcut |
|---|---|
| Editor only | ⌘1 |
| Editor and note list | ⌘2 |
| Editor, note list and folders | ⌘3 |
| Focus mode | ⇧⌘J |
| Fold / unfold section | ⌘' |

## Formatting

| Action | Shortcut |
|---|---|
| Bold | ⌘B |
| Italic | ⌘I |
| Link | ⌘K |
| Link and fill title | ⌥⌘K |
| Follow link | ⌃Return or ⌘-click |
| Bullet list | ⇧⌘8 |
| Toggle task | ⌘. |
| Comment | ⌘/ |
| Clear formatting | ⌥⌘⌫ |
| Paste and match style (or paste a URL without its title) | ⌥⇧⌘V |
| Indent / outdent (moves list items a level) | Tab / ⇧Tab |

## Selection and editing

| Action | Shortcut |
|---|---|
| Undo / redo | ⌘Z / ⇧⌘Z |
| Expand selection | ⌃⇧⌘→ |
| Shrink selection | ⌃⇧⌘← |
| Expand selection to line | ⌘L |
| Add next occurrence | ⌘D |
| Add every occurrence | ⇧⌘L |
| Remove last occurrence | ⌘U |
| Add a cursor above / below | ⌥⌘↑ / ⌥⌘↓ |
| Add a cursor | ⌘-click |
| Column selection | ⌥-drag |
| Back to one cursor | Escape |

## In the note list

| Action | Shortcut |
|---|---|
| Move selection | ↑ / ↓ |
| Extend selection | ⇧↑ / ⇧↓ |
| Add to selection | ⌘-click |
| Select a range | ⇧-click |
| Open in a new window | Double-click, or Return |

## In the palettes

| Action | Shortcut |
|---|---|
| Choose | ↑ / ↓, or ⌃P / ⌃N |
| Run or open | Return |
| Close | Escape, or the same shortcut that opened it |
| Switch Go to Note to text search | type `/` |

## In a note's title

| Action | Shortcut |
|---|---|
| Rename and start writing | Return |
| Cancel | Escape |
