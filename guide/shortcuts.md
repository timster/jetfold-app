# Keyboard Shortcuts

Every command is also in the command palette (⌘P), including the ones without a shortcut.

## Notes and windows

| Action | Shortcut |
|---|---|
| New note | ⌘N |
| New note from template | ⌥⌘N |
| New folder | ⇧⌘N |
| Open today's note | ⌘T |
| Show note history | ⇧⌘H |
| Note Info | ⌥⌘O |
| Commit changes | ⇧⌘K |
| Export as PDF | ⇧⌘E |
| Move selected notes to another folder | ⇧⌘M |
| Remove the selected tag from every note | ⌘⌫ |
| Show the main window | ⌘0 |

## Finding

| Action | Shortcut |
|---|---|
| Command palette | ⌘P |
| Go to note | ⌘O |
| Search in notes | ⇧⌘F |
| Go to heading | ⇧⌘O |
| Go to Tasks | ⌥⌘L |
| Go to Agenda | ⌥⌘A |
| Back / Forward | ⌘[ / ⌘] |
| Find and replace | ⌥⌘F |

## View

| Action | Shortcut |
|---|---|
| Editor only | ⌘1 |
| Editor and note list | ⌘2 |
| Editor, note list, and folders | ⌘3 |
| Focus mode | ⇧⌘J |
| Fold / unfold section | ⌘' |

## Formatting

| Action | Shortcut |
|---|---|
| Bold | ⌘B |
| Italic | ⌘I |
| Link | ⌘K |
| Link and fill title | ⌥⌘K |
| Follow link | ⌃Return or ⌘-click |
| Bullet list | ⇧⌘8 |
| Toggle task | ⌘. |
| Comment | ⌘/ |
| Clear formatting | ⌥⌘⌫ |
| Indent / outdent a list item | Tab / ⇧Tab |

## Selection and editing

| Action | Shortcut |
|---|---|
| Expand selection | ⌃⇧⌘→ |
| Shrink selection | ⌃⇧⌘← |
| Expand selection to line | ⌘L |
| Add next occurrence | ⌘D |
| Add every occurrence | ⇧⌘L |
| Remove last occurrence | ⌘U |
| Move line up / down (list items move with sub-items) | ⌥↑ / ⌥↓ |
| Add a cursor above / below | ⌥⌘↑ / ⌥⌘↓ |
| Add a cursor | ⌘-click |
| Column selection | ⌥-drag |
| Back to one cursor | Escape |

## In the note list

| Action | Shortcut |
|---|---|
| Open in a new window | Double-click |

## In the palette

| Action | Shortcut |
|---|---|
| Choose | ⌃P / ⌃N, as well as ↑ / ↓ |
