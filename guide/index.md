# Jetfold Guide

Jetfold is a fast, native notes app for macOS that works directly on a folder of plain Markdown files. Nothing is locked away in a database: every note is an ordinary `.md` or `.txt` file you can open in any other editor, sync with any service, or keep in a git repository.

## The ideas behind Jetfold

- **Your files stay yours.** Jetfold reads and writes the Markdown files in your folder exactly as you typed them. It never rewrites your formatting, adds hidden metadata, or changes the file format.
- **What you see is what you wrote.** The editor hides Markdown symbols while you read and shows them again as soon as your cursor is inside them, so a note looks finished but is still easy to edit.
- **As much or as little as you like.** Tasks, agenda, tags, the calendar and your own views are all switches. Turn them off and Jetfold is a folder of notes and an editor.
- **Everything is a keystroke away.** Almost every action is in the menus with a shortcut, and all of them are in the command palette (⌘P).
