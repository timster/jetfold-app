Everything in the box

Jetfold has tools for writing, linking, finding and planning.
Your notes remain plain text on your Mac.

Writing

You see formatting as you write, and the file underneath remains plain Markdown.

  • Tables you edit in place
  • Callouts, footnotes, and math
  • Syntax highlighting for code
  • Diagrams drawn from text
  • A slash menu for inserting blocks
  • Multiple cursors and regex find
  • A built-in calculator
  • Images you resize by dragging
  • Vim mode and line numbers
  • Focus mode
Writing in the guide

Linking

Link notes to each other. Links update when you rename or move a note.

  • Links to notes and headings
  • Previews when you point at a link
  • Backlinks
  • Embeds from other notes
  • Turn a selection into a new note
  • Titles filled in for pasted web links
Links in the guide

Finding

Search all your notes, including text in photos and scans.

  • Instant full-text search
  • Text in photos and scans
  • Nested tags
  • An agenda of dated tasks and events
  • Custom views
  • Back and forward between notes
  • Word counts and an outline
Finding things in the guide

Organizing

Notes are just Markdown files. If you change them in other apps, your changes are reflected in Jetfold.

  • One, two or three columns
  • Drag and drop for notes, folders and files
  • Pinned and read-only notes
  • Multi-note editing
  • Notes in separate windows
  • Customizable sidebar with custom views
Folders and notes in the guide

Canvases

Arrange notes, text cards and images on an endless canvas.

  • Notes as cards on the board
  • Images, files, and web links
  • Labels, groups, and colors
  • Included in search and backlinks
  • Export to PDF, PNG, HTML, or Markdown
  • Fully supports JSON Canvas
Canvases in the guide

Daily notes and capture

Write down a thought from any app, and find notes by date in the calendar.

  • A shortcut that opens today's note
  • A calendar of daily notes and due dates
  • Templates
  • Send text from any app
  • Links that open a note from other apps
Daily notes in the guide

Part of your Mac

Jetfold works with Continuity Camera, widgets, Focus, Shortcuts and Spotlight.

  • Photos, scans, and sketches from your iPhone
  • Copy text from pictures
  • A Today widget
  • Focus filters
  • Shortcuts, Siri, Spotlight, and Share
  • A toolbar you can customize
Jetfold and other apps in the guide

Git

If your notes folder is a git repository, you can restore earlier versions of a note without opening Terminal.

  • A list of changed notes
  • Changed lines are marked in the editor
  • The full history of a note
  • Restore an earlier version
  • Commit without leaving Jetfold
Git in the guide

Sharing

Export a note as a formatted document, images included.

  • PDF and HTML, with images
  • EPUB for e-readers
  • TextBundle and plain text
Exporting in the guide

Peace of mind

Notes are saved as you type. If another app changes a note you're editing, you choose which version to keep.

  • Saved as you type
  • Live updates from other apps
  • No silent overwrites
  • A list of unused attachments
  • Works with iCloud Drive
  • No account or analytics, and no data collected
