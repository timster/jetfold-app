Everything in the box

A tour of what Jetfold does, from the editor to git.
Every part beyond your folders and notes can be switched off.

Writing

The editor renders Markdown as you type and shows the markup again when your cursor is inside it.

  • Formatting shortcuts
  • Tables you edit in place
  • Callouts, footnotes, math, and highlighted code
  • Mermaid diagrams
  • A slash menu for inserting blocks
  • Multiple cursors, Expand Selection, and regex find
  • A calculator: type 12*4= and press Return
  • Focus mode
Writing and formatting in the guide

Linking

Notes link to each other, and the links follow them when they move.

  • Type [[ to link to another note
  • Hover over a link to preview the note
  • See every note that links to the one you're in
  • Embed part of another note
  • Turn a selection into a new note
  • Paste a URL to get a link with the page title
Links in the guide

Finding

Palettes for notes, words, headings, and commands, and views that gather what's spread across your notes.

  • Fast full-text search
  • Search finds words in pictures and scanned PDFs
  • Nested #tags in the sidebar
  • @dates that feed an agenda
  • Tasks, Agenda, and custom views
  • Back and forward between notes
  • Note Info with word counts and an outline
Finding things in the guide

Organizing

Folders are folders. Arrange them however you like, and Jetfold keeps up.

  • Three panes (folders, notes, editor), two (notes and editor), or just the editor
  • Drag and drop notes, folders, and tags
  • Pinned and read-only notes
  • Edit several notes stacked in one pane
  • Open any note in a separate window
  • Rearrange the sidebar and hide what you don't use
Organizing notes in the guide

Canvases

A board for thinking in space: text, notes, images, and links, joined by arrows.

  • Text cards and editable note cards
  • Images, files, and web links
  • Arrows with labels, groups, and colors
  • Included in search and backlinks
  • Export to PDF, PNG, HTML, or Markdown
  • Saved as open JSON Canvas files
Canvases in the guide

Daily notes and capture

Get a thought down from anywhere, and find it again by date.

  • Open today's note with ⌘T
  • A calendar in the sidebar
  • Send selected text from any app to your Inbox
  • jetfold:// links for Shortcuts and scripts
  • Copy a link to any note
Daily notes in the guide

Part of your Mac

Jetfold works with the rest of macOS, the way a Mac app should.

  • Photos, scans, and sketches from your iPhone
  • Copy text from pictures and scanned PDFs
  • A Today widget with what's due
  • Focus filters
  • Shortcuts, Siri, Spotlight, and the Share menu
  • A toolbar you can customize
Jetfold and other apps in the guide

Git

If your notes folder is a git repository, Jetfold shows what changed and keeps every version a click away. Everything stays on your Mac.

  • Status indicators on notes and folders
  • Changed lines marked as you type
  • Full note history
  • Restore any version
  • Commit from the palette
Git in the guide

Sharing

Hand a note to someone who doesn't use Jetfold.

  • HTML and PDF export includes images and code blocks
  • EPUB for e-readers
  • TextBundle and plain text
Exporting in the guide

Peace of mind

Your words are saved, and they're never overwritten by surprise.

  • Autosave as you type
  • Changes from other apps show up live
  • Asks before overwriting outside changes
  • Finds attachments no longer used in any note
  • Works with iCloud Drive
  • No account, no analytics, nothing sent anywhere (see our privacy page for more details)
