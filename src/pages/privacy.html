Privacy

Jetfold doesn't collect any data about you or your notes.

The app

  • Your notes stay where you put them. Jetfold reads and writes the files in the folder you choose. It has no account, no server and no copy of your notes anywhere else.
  • No analytics or tracking. Jetfold doesn't record how you use it and doesn't include any third-party code that does.
  • Settings stay local. A notes folder's settings are kept in a .jetfold folder inside it. The list of folders you've opened is kept on your Mac.
  • Git stays on your Mac. Jetfold commits to your notes folder's repository but never pushes or pulls.

When Jetfold uses the internet

Jetfold only connects to the internet for something you've asked for:

  • Link titles. When you paste a web address, Jetfold fetches that page to fill in its title. Turn this off in Settings → Editor → Fill in link titles when pasting a URL.
  • Web images. If a note shows an image from a web address, Jetfold loads it from there, as a browser would.

Those requests go straight to the sites in question. Nothing is sent to the developer.

Purchases

The free trial and the unlock are App Store purchases, handled by Apple. Jetfold only asks the App Store whether they've been bought on your Apple Account; it never sees your payment details.

This website

jetfold.app uses no cookies. It counts page visits with GoatCounter, which collects no personal data and doesn't track you across sites. It's hosted on GitHub Pages, and GitHub may log visits as described in the GitHub Privacy Statement. The themes page remembers the theme you picked in your own browser.
