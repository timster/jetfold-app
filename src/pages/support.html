Where are my notes stored?
In the folder you choose, as ordinary .md and .txt files. Jetfold doesn't keep a database or a copy anywhere else. Each folder's settings are in a .jetfold folder inside it.
Can I use the notes I already have?
Yes. Choose the folder that holds them, and they show up straight away. Nothing is imported or changed.
Does Jetfold sync?
Jetfold works on a folder, so any service that syncs folders syncs your notes: iCloud Drive, Dropbox, or a git repository. Changes that arrive while Jetfold is open show up live.
What happens if a note changes in two places?
If a file changes on disk while you have unsaved edits, Jetfold asks which version to keep. It never overwrites either one quietly.
Do I need git?
No. If your notes folder is a git repository, Jetfold shows changes and history and can commit for you. If it isn't, none of that appears.
Can I hide the features I don't use?
Yes. Tasks, Agenda, tags, the calendar and your views are all switches in the View menu. With them off, Jetfold is a folder of notes and an editor.
Which Macs does it run on?
Any Mac with macOS 14 Sonoma or later.
